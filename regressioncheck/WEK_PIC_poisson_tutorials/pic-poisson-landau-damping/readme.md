# PIC Tutorial Reggie `pic-poisson-landau-damping`
this reggie
- is based on the tutorial: `~/piclas/tutorials/pic-poisson-landau-damping/`
- runs it without changing any parameters in pyhope.ini or parameter.ini
- pyhope.ini and parameter.ini are symbolic links to the tutorial directory
- requires `PICLAS_READIN_CONSTANTS = ON` to set the following constants

      c0  = 1.e8
      eps = 1.
      mu  = 1.e-16
