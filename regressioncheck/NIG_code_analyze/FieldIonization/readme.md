# FieldIonization
- Tests the field ionization module by activating Part-DoFieldIonization = T
- Varies the following parameter.ini settings
  - FieldIonizationModel = 1,2
  - Part-Species1-Init1-ParticleNumber = 1,0,0
  - Part-Species3-Init1-ParticleNumber = 0,1,0
  - Part-Species7-Init1-ParticleNumber = 0,0,1
